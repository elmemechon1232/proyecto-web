
# proyecto-web
Pagina web para la comuna "Destino Cordillera", sitio turistico fictiocio creado para la prueba solemne 1 de la asignatura desarrollo de aplicaciones web

Nombre del proyecto: Plataforma de Turismo Local Destino Cordillera

Integrantes: Matias Palma - Jazmin Ruz - Emerson Gálvez

Descripcion sitio: es un sitio web donde se puede acceder a los principales panoramas, alojamiento y gastronomia local de Destino Cordillera.

Instrucciones: el sitio cuenta con 4 pestañas: Inicio - Panoramas - alojamiento y gastronomía - Reserva y contacto.

Tecnologias: HTML5, CSS3, Bootstrap 5, git y github
